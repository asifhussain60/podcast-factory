# Architecture decision records

One file per decision, numbered and never renumbered. A superseded ADR keeps its
file and gains a `Superseded by: NNNN` line at the top rather than being edited
into agreement with the present.

Amendments made during review are marked inline at the point they apply and
collected in a closing section, so the record shows what was proposed, what was
checked against the code, and what changed as a result.
