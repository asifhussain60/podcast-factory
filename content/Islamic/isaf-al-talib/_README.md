# Is'af al-Talib fi Jami' al-Matalib

**Source:** *Kitab Is'af al-Talib fi Jami' al-Matalib* ("The Book of Aiding
the Seeker in All Requests/Demands"), Part One (A) — Faidh Ali bin Sayyidna
Sulaiman (Shams al-Kiyan). Shar'i (jurisprudential) matters arranged
following the order of Da'a'im al-Islam. Translated from the handwritten
Arabic original (primary source), cross-checked against the Urdu
translation by Mawlvi Amiruddin Sahib where the Arabic OCR is uncertain —
see `_source/SOURCES.md`.

**Slug:** `isaf-al-talib` · **Category:** `books` · **Content profile:** `islamic_scholarly` (translation edition).

## No podcast lane for this book

`skip_podcast: true` in `_system/series-config.yaml` — this book produces
chapters, an articulated reading edition, read-aloud narration, and
per-chapter slide decks, but **no NotebookLM two-host podcast episodes**.
The upload-checklist / episode-framing steps that a standard scaffold
README describes do not apply here.
