#### SL-P3: Structure-vs-Description — 8 moments name a type and supply none of its commitments

`slide-deck-patterns.md` states, per type, what the source MUST specify. **Annotated Structure** requires the whole, parts named *with positions*, and one annotation per part. **Hierarchy** requires named levels *and parent-child relations*. Each moment below declares its type and supplies none of that type's structural commitments, so NotebookLM has nothing to draw from and will render a bullet list that nonetheless carries a diagram-type label. This is the deck's dominant defect: "Annotated structure" is being used as a default container for labelled prose.
