# Pronunciation — Degrees of Excellence (book-specific overrides)

Rung 0 of the term ladder in `scripts/podcast/knowledge/term_render.py`: whatever
this table says a term sounds like beats the loanword list, the exonym table, the
cross-book ledger and the plain transliteration below it. A human who has heard
the audio outranks every heuristic — which is exactly why a value here has to be
one somebody actually heard.

Format: pipe table. Only the FIRST table in this file is read; the withdrawn
record below it is a bulleted list on purpose.

A value of `plain` means **this term matters in this book, but nothing is claimed
about how it sounds** — the ladder resolves it on its own. The row stays because
the pronunciation probe builds its term inventory from this table, so deleting a
row would drop the term from the very run meant to settle it.

## What the probe found (run 1, 2026-08-01)

The table was filled on 2026-08-01 with 40 hyphen-CAPS respellings, written by
ear from the transcripts of the first audio run and shipped without anyone
hearing one spoken. The pronunciation probe then spoke nine of them:

| Told to say | Came out as | |
|---|---|---|
| `al-Kirmani` (no override — plain) | "Al-Kirmani" | correct |
| `tow-HEED` | "toheed" | correct |
| `tash-BEEH` | "Tashbieh" | correct |
| `an-nay-saa-BOO-ree` | "Ani Saburi" / "Aizab Uri" | wrong, two ways |
| `vice-JEER-uhnt` | "vice jeer hunt" | wrong |
| `wa-LAA-ya` | "wa la ya" | wrong |
| `SAA-is` | "a SAA, is" | wrong |
| `KHUT-bah` | "KHU Tiba" | wrong |
| `NOOR al-i-MAA-ma` | "NO or Ali Masma" | wrong |

Five of the seven failures split at the hyphens and read the pieces as separate
words. **Imam** and **Khalifa**, which nobody instructed, came out perfect.

So the two proven values stay and the other 38 are withdrawn — not deleted, and
not replaced by a guess. Run 2 tests the ladder's plain forms across the whole
list, and any of these can be reinstated the moment a probe hears it work.
